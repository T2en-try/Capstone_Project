# CPU-only PyTorch wheel index -- this project's deploy target has no GPU
# (confirmed). --extra-index-url (not --index-url) so pip still resolves every
# other package from PyPI as normal; only torch/torchvision come from here.
# Without this, pip installs the default CUDA-bundled wheels, pulling ~1-2GB of
# nvidia-*/cuda-* packages that are never used and were most of the ~11-minute
# cold-build time measured this session -- not the baked-in model/GIS-cache
# files, which cost ~0.6s at the COPY . . layer (see
# docs/production_migration_log.md for the measured before/after).
--extra-index-url https://download.pytorch.org/whl/cpu
